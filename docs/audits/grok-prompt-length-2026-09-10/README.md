# Grok 视频接口长度调查（2026-09-10）

## 结论

当前配置 `https://ybw-ai.com/v1/videos/generations` 对解码后的 prompt 表现为 4096 UTF-8 字节上限。此结论来自真实接口边界对照，不代表 Grok 网站或所有 Grok API 的共同限制。

| 输入 | 字符数 | UTF-8 字节数 | 结果 |
|---|---:|---:|---|
| 原剧本 | 1827 | 5072 | HTTP 400，Prompt length exceeds the maximum allowed length of 4096 |
| 原剧本，JSON 中文改成 Unicode 转义 | 1827 | 5072 | 同一 HTTP 400；排除 JSON 转义形式影响 |
| ASCII a × 4096 | 4096 | 4096 | 获得校验任务回执 |
| ASCII a × 4097 | 4097 | 4097 | HTTP 400 长度错误 |
| 中文 灯 × 1365 | 1365 | 4095 | 获得校验任务回执 |
| 中文 灯 × 1366 | 1366 | 4098 | HTTP 400 长度错误 |

边界请求使用 `data:image/png;base64,AAAA` 无效图片。短提示词的先行对照已确认该图片会产生异步 invalid_image 失败；通过长度检查的边界任务同样查询最终失败，不生成成片。具体回执与最终状态见 evidence.json。

## 调用链核对及范围

本地 `studio.request` 将已确认的 Grok 剧本原样放入 `prompt`；图片单独放在 `image.url` 中。无额外剧本扩写。插件使用 xAI 原生 `/v1/videos/generations` 格式。

网关公开前端引用 Wei-Shaw/sub2api 项目。核对该项目上述 commit：`backend/internal/service/grok_media.go` 的视频处理保留 prompt，无此 4096 检查；可改写模型、图片结构并转发上游报错。公开代码不能证明线上部署版本和上游配置，因此目前无法从客户端断言限制具体位于网关定制代码还是其上游。没有访问供应商管理接口或其他用户数据。

## 本地修正

撤销没有充分依据就加入的全局字节硬限制，以及强制 1000 字符的剧本规则。Grok 保持原剧本直传；长度错误保留供应商原文并记录字符数、UTF-8 字节数、服务主机，不静默截断或自动重复付费。

原剧本完整保存在 original-script.txt。先前精简后的成片仅证明短请求能够生成，不等于原剧本的接口兼容问题已修复。要让此接口接受原剧本，需要该服务端放宽或修正限制，或使用已验证支持原剧本的调用链；本地不擅自切换服务或上传凭据到其他主机。
