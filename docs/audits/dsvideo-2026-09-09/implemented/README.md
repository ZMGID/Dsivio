# 视频工作台流程与 UI 调整

2026-09-09。按审查结果实现，继续使用侧边栏。

## 已完成

- 视频创作、参考仿拍、视频拆解三个入口；模板库与最近任务保留。
- 仿拍并排接收参考视频和商品素材，支持两类文件一起拖入。拆解后直接带入商品和参考结构继续制作，不要求先存为模板。
- 修复分析重点、报告语言没有传给 Agent 的问题。
- 宽泛需求由导演返回三个拍法，用户选择后展开完整方案；已有模板或明确方案直接进入剧本。
- 默认以 Markdown 展示方案，可切换全文编辑；确认后自动转换提示词、查询报价。实际生成仍需用户确认所选服务与费用。
- 每个入口独立保存本机草稿，切换或重新打开页面能恢复；任务自动命名。
- 已知运行任务每 8 秒读取最新任务并查询状态，结束后停止；提交状态不明不会自动重提，保留人工核查和补录编号入口。
- 声音默认按要求设计；高级参考模式、配乐和首尾帧控制收进展开区；普通界面不再出现工作流百万像素、选择助手和多供应商数量说明。
- 修正内置主技能中禁止 UGC/口播却携带 UGC 模板的冲突。没有修改上游 GitHub 仓库。

- TypeScript、修改文件 ESLint、前端生产构建通过。
