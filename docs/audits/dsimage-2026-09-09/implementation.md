# dsimage 功能页实施记录

2026-09-09。按用户要求保留 dsimage 五条独立出图流程，模板制作移到次级工具区。原 skill 文档是行为对照资料；此次改动落在 Dsivio 的 React 页面和 Rust 图片工作台，未执行 skill 的出图指令。

## 功能分工

| 页面 | 路线 | 用户需要做什么 |
| --- | --- | --- |
| 单张 / 改图 | gen | 写要求，可选上传参考图，直接生成 |
| 样图换货 | replace | 提供现成样图或换货模板，再提供新商品，开始换货 |
| 模板套图 | smart | 选已有模板、添加商品，生成同风格套图 |
| 从零设计 | design | 添加商品和要求，自动设计并试做 |
| 多品类批量 | client | 导入商品文件夹、填写共用要求，自动分类并逐类试做 |

“制作模板”“模板库”“任务”放在下方工具区。样图换货和从零设计会自动组织所需模板，不需要先去制作模板页。

## 界面调整

- 紧凑上传区与需求输入、规格、主按钮同屏；换货与模板套图分别采用两栏素材选择。
- 默认只保留素材与要求、生成结果两个阶段；画面安排和完整提示词按需查看。
- 正背面选择、商品款型、分类与模板绑定等内部输入从主流程移除。
- 单张默认无文字，换货默认跟随样图，新设计默认中文。已有模板保留完整语言规则，界面显示简短语言摘要。
- 平台、风格、清晰度和补充商品信息收进更多设置；结果中的模板保存默认折叠。
- 草稿自动保存，失败时显示恢复入口；动作前保存原生任务。
- 多品类结果按当前分类显示。只有该类还有剩余商品时，才显示样品确认与批量入口。

## 后台衔接

- 新增 start 动作，串起素材识别、所需视角补生成、模板组织、页面规划和样品生成。
- 看实际图片识别正背面，不依靠文件名；缺失且需要的视角自动生成，并由模型检查商品一致性。
- 内部参考素材单独持久化，不计入样品完成条件或交付图片。保留原图与生成参考的来源区别。
- 模板制作时将每页所需视角转换为受控素材引用；背面页实际引用准备好的背面图。
- 多品类任务自动归类，每类建立模板并选取前两款试做；不足两款时全部生成。
- 批量仍需用户确认样品。远程请求保存编号并恢复查询；记录为失败的请求需下一次明确重试才重新提交，未收到响应的中断记录不会自动重复下单。

## 验证

- 图片界面测试：8 个文件，46 项通过。
- Rust 图片工作台测试：34 项通过。
- TypeScript 检查、本次修改文件的 ESLint、前端生产构建、git diff --check 通过。
- 整个图片目录的严格 ESLint 仍有 RequirementOptimize.tsx 原有的 3 条警告；该文件未修改。构建也保留仓库原有的包体积等警告。
- 在 1277 × 720 浏览器预览中检查六个入口，并额外检查模板选择后的语言与规格显示。

本轮没有调用真实图片 API，未验证模型识别准确率、缺失视角的实际生成质量或真实供应商的完整出图链路。浏览器只提供界面预览；素材导入和生成需在 Dsivio 桌面运行时执行。
