# Dsimage UI 排版调整 · 2026-09-09

## 本轮调整

- 按用户反馈，五个创作功能恢复为紧凑侧边栏；模板与记录分组排列，图片设置放在底部。保留本轮表单布局与视觉样式。
- 单张、从零设计和批量页面使用左侧素材、右侧要求的工作区；样图换货和模板套图并排展示来源与目标商品。
- 统一标题层级、间距、输入框、边框和按钮；收紧上传空状态，主操作放在表单底部。
- 无示例图的模板显示页面目录，完整规则保留在详情预览。
- 所有样式限定在图片工作台，沿用现有主题变量；适配窄窗口和减少动态效果偏好。

## 验证

- 图片模块 8 个测试文件、46 项测试全部通过。
- TypeScript 检查、修改文件的 ESLint 检查、前端生产构建通过。
- 构建仍有已有的大包体积提示。
- 浏览器检查：单张空状态、已放素材、样图换货、制作模板、模板库；990 × 800 窄窗口无横向溢出。
- 浅色和深色检查覆盖已放素材状态。深色通过预览页应用现有 dark 类检查样式，未测试设置页面切换。
- 本轮未调用生图 API。截图中背包来自仓库内置模板，仅作为隔离预览页面的演示素材。
