# 图片与视频任务管理

视频工作台新增“任务”入口，图片任务页共用同一套列表。聊天与工作台仍读取各自原有的任务记录；Skill 提供制作流程，内置插件执行功能，`studio` 负责聊天工具与任务数据之间的衔接。

支持名称、要求、编号搜索，状态和类型筛选，更新时间或名称排序，每页 24 项，置顶、批量归档和恢复。视频侧栏只保留最近 6 项，完整记录在任务页查看。打开任务读取最新版本，保留原有编辑保存机制。

归档和置顶单独保存在各领域的 `task-library.json`，不改任务版本、生成状态、素材或结果。后端整批校验后原子写入；运行中、提交中和等待核查的任务不能归档。归档任务重新运行时重新出现在活动列表。

视频任务页每轮最多查询 3 个正在运行的远程任务，轮换查询其余任务；页面隐藏时暂停。此路径只查询已存在的任务，不提交生成请求。

- 本次组件的 ESLint 检查通过。工作区全量 TypeScript 检查一度被并行修改的拖放组件阻塞。提交时将拖放、模型定价等无关改动排除，在暂存快照中重新验证：完整 TypeScript 检查通过，6 个前端测试文件共 56 项通过，Python 聊天结果持久化测试通过。
