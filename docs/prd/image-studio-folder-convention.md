# 图片工作台保存目录规范

适用范围：独立「图片」页面。功能入口和制作步骤沿用原有布局，包含「制作与试品」。

## 默认保存位置

系统「图片」目录下的 `Dsivio/Images`。本机通常为 `C:\Users\11028\Pictures\Dsivio\Images`；若 Windows 已重定向图片库，以「图片设置 → 图片保存位置」显示的实际路径为准。

在图片设置中选择根目录并保存，对之后新建的任务生效。任务首次保存时固定自己的目录，后续改名、重新出图、修改默认位置都不移动这个任务的已有文件。

```text
Images/
└─ 2026-09-09_背包套图__任务ID/
   ├─ originals/
   │  └─ 背包A__商品ID/
   │     ├─ h1_r0001_成图ID.png
   │     └─ h1_r0002_另一成图ID.png
   └─ deliveries/
      └─ 20260909-153000_r0002_导出ID/
         ├─ 背包A__商品ID/
         │  └─ h1_成图ID.jpg
         └─ manifest.json
```

## 保存规则

- 生成完成一张立即保存一张，不需要点击导出。`originals` 保留图片接口返回的原始文件及实际格式、分辨率。
- 任务名、商品名保留可读部分；特殊字符转换为下划线。ID 区分同名任务、同名商品和重复生成结果。
- `r0001` 是任务需求版本；同一版本多次修改或重试，使用不同成图 ID，不覆盖旧图。
- 「导出」复制当前需求版本每页的最新有效成图。每次导出新建一批目录；若某页的最新尝试失败，不把更旧的成功图冒充当前结果。
- 导出默认放进当前任务的 `deliveries`；现有导出窗口显示位置，无需每次再选目录。
- 调整交付尺寸或大小只处理副本。宽、高和大小全部为 0 时原样复制；调整尺寸时等比缩放、补白、生成 JPG。
- `manifest.json` 记录本次交付的任务、版本、商品、页面、源成图 ID 和提示词。

## 素材与旧任务

导入素材不修改原文件。批量导入时选择包含多个商品文件夹的父目录，每个直接子文件夹是一款商品，深层文件夹视为该商品的素材。不同路径下同名商品不会合并；文件按 `h1、h2、h10` 的自然顺序排列。

任务记录、导入素材和模板仍由应用数据目录管理。已有任务的旧成图不自动搬迁，仍可预览和导出；后续新成图存入新分配的任务目录。请从应用内更换保存位置，不要手动移动已在使用的任务目录。

内置聊天通过宿主 `studio` 工具使用同一任务和保存目录。没有宿主工具的外部 CLI 调用原版 dsimage 脚本时，仍使用用户指定的输出目录及 `_dsimage/batch.json`；与页面共享模板，不互相覆盖任务格式。详细路径解析见内置 Skill 的 `guides/studio.md`。
