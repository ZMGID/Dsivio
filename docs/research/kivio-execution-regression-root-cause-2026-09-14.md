### 失败状态失真：已复现，优化前已有

当前与`4e3141a2`都通过Git Bash `-c`执行命令，没有默认pipefail。工具反馈因此可能同时包含失败正文、`exit_code: 0`和`is_error: false`。

本地无副作用探针：

```text
(打印模拟错误; exit 2) 2>&1 | tail -5
  bash -c => exit 0
  bash -o pipefail -c => exit 2
(exit 2); rc=$?; echo driver_exit:$rc
  bash -c => exit 0，正文 driver_exit:2
```

所以仅加pipefail不能修复尾部echo覆盖退出码的情形。需要完整日志与主测试进程状态形成一致的工具结果。上次完成轮也出现失败测试接管道并返回0；这是原有执行反馈缺陷，本轮验证路径让它更突出，不是这次精简新引入。
