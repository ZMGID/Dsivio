macOS 安装包未签名。首次启动可右键选择「打开」，或执行 `xattr -cr "/Applications/dsivio.app"` 后打开。
The macOS build is unsigned. On first launch, right-click and choose Open, or run the command above.

## 新版本亮点 / What's New

- **工作台**：集中提供店铺、商品档案、上架、图文创作、图片、视频、发布与素材管理入口。 / A unified workbench for shops, product archives, listings, writing, images, video, publishing and assets.
- **媒体创作**：整合内置 Dsvideo、媒体模型参数、系统配音、本地转写和任务取消能力。 / Integrated Dsvideo, configurable media models, system speech, local transcription and task cancellation.
- **电商插件**：新增紫鸟店铺日报、Shopee 调研与同款 SKU 搜索，支持带图片和回查标识的 Excel 报告。 / New daily shop reports, Shopee research and matching-SKU search with illustrated Excel reports and lookup identifiers.
- **对话与自动化**：改进长对话渲染、项目指令加载、定时发送和工作流状态恢复。 / Improved long-conversation rendering, project instructions, scheduled sends and workflow state recovery.
- **修复与交付**：修复美客多类目校验和报告脚本同步；安装包通过双平台资源检查后统一发布。 / Fixed Mercado Libre category validation and report script synchronization; installers are published after both platforms pass resource checks.
