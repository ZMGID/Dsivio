# 工作台的 AI 调用走同一个无会话入口

工作台要的 AI 有两种形状：写一条提示词（模型最多用一轮工具），以及写文案、分析再落盘（多轮工具）。两种都可能带工具，所以不是「纯文本」和「Agent」两条路径。

`run_ai_task` 是唯一入口，内部就是 `run_agent_loop`。`mode: once | agent` 只改三件事：工具轮次上限（once 为 1，agent 用设置值）、超时（60s / 600s）、要不要发 `ai-task-delta`。会话 id 是 `wb_{taskId}`，自动批准工具，不创建侧栏会话。自动化节点用同一份 `HeadlessAgentHost`，不再各写一个自动批准的 host。

提示词内容留在页面的纯函数里，不进 Rust。标题总结、提问优化、vision 仍走各自的调用，以后可以收进这个入口，不在这次迁移。
