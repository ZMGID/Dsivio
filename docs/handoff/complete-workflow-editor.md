# 电商工作流编辑器完善

状态：编辑器及常用节点后端执行已接通；真实供应商生成待实跑。2026-09-22 用户最新请求已扩展到 UI 交互、画布和后端，下方“仅前端/不接执行/不使用浏览器”为历史范围，不再描述本轮。当前实施记录见文末。

## 目标与边界

把现有前端粗模完善为能配置、编排、保存和重新打开的编辑器。本轮完成前端编辑闭环，不实现工作流执行后端，不请求付费模型。用户已确认先做画布、节点配置和编排交互；不要做到计划阶段就停下。

遵循 `docs/engineering-standards.md`、`CONTEXT.md`、ADR 0006/0007/0008。简单的事不要复杂化，不增加通用节点插件系统、规则引擎或任务平台。用户未授权浏览器：不使用浏览器或 UI 自动化，报告中明确未做实机视觉验收。

## 现状与入口

- `src/chat/workbench/workflow/WorkflowPage.tsx`：列表、新建、模板、JSON 导入导出。
- `WorkflowCanvas.tsx`：ReactFlow 画布、节点添加/移动/删除、同类型端口连线、250ms 草稿保存；运行按钮仅显示提示。
- `WorkflowNodeCard.tsx`：静态节点卡与端口，没有参数编辑。
- `workflowModel.ts`：节点只有 id/kind/title/position/note，没有配置字段。
- `workflowCatalog.ts`：25 种节点描述与图片复刻示例；单图、多图尚未区分，部分节点只是占位。
- `workflowStore.ts`：`kivio.workbench.workflows` 本机 localStorage 草稿与导入解析。

先读取这些文件及邻近样式、测试、模型选择和素材选择组件，确认主工作区最新实现。原桌面自动化有独立模型与运行器，本轮不合并。

## 实施范围

### 1. 节点参数与配置入口

- 沿用现有画布和视觉规范，在选中节点时提供就近配置区，优先右侧配置面板；不重做 Workbench 整体布局。
- 节点支持改名、备注；卡片显示关键配置摘要和待补充项，端口显示业务名称，不能只有“图片/文本”。
- 本轮完善：`image.upload`、`image.uploadMany`、`video.upload`、`prompt.input`、`image.understand`、`image.generate`、`video.generate`，以及 text/image/video 的预览、下载和多图输出节点。输出节点只提供实际需要的配置，不为凑表单虚构参数。
- 素材输入能选择、更换、移除并查看已选素材；提示词可编辑；理解节点可填分析指令；生成节点可选现有模型并按已有能力配置必要参数。复用现有模型目录、选择组件与参数定义，不硬编码供应商清单，不修改全局默认模型。
- 上游连线与本地配置的关系必须明确：连线供值时展示来源；断线后恢复本地配置。必需输入可由有效本地值或连线提供，不维护两套重复绑定状态。
- 节点参数使用按 kind 区分的明确类型或同等简单的类型安全表达，和节点一起保存；不只存在 React 临时 state。未配置的旧草稿有合理空值/默认值。
- 其他节点保持可读取，明确尚未完善，不能伪装全部 25 种都能配置或执行；不删除旧草稿中的条件、循环、3D 等节点。

### 2. 画布编辑与连线

- 保留添加、移动、缩放、适应画布、选择、删除；补节点复制和撤销/重做。复制产生新 id，配置独立，不意外复用原节点的连线。
- 撤销/重做覆盖节点增删、移动、配置和连线编辑；一次拖动为一步，连续文本编辑合理合并，不逐像素或逐字符堆栈。保存与重新打开以当前快照为准，不要求持久保存撤销历史。
- 快捷键仅在编辑器合适的焦点下生效；输入框中的删除、复制、撤销保持文本编辑语义。
- 明确单张与多张端口、必填与可选、一个输入可接几条线。禁止无效端口、自连、重复连接和单值输入重复接线，并给出简短原因；普通数据流不允许环，不借此实现循环引擎。删除节点同时删除关联边。
- 连接规则、配置默认值各只有一份负责人，目录内就近实现；不分别在面板、画布、存储中复制同一规则。

### 3. 保存、恢复和示例

- 沿用现有本机草稿存储与导入导出，保证名称、备注、参数、素材引用、位置和边保存恢复完整。旧无 config 草稿可继续打开；导入不静默丢弃已支持参数。
- 复用已有持久素材引用方式；不要把 blob URL/File 对象当成持久数据，不把大视频 base64 塞进 localStorage。临时素材离开后不可恢复时保留描述并提示重新选择；JSON 不假装打包了本机素材，跨机器不可访问时明确提示。
- 保存失败有可见反馈，不能仍显示保存成功。不为本轮建立新素材库或后端文件管理系统。
- 完善现有图片复刻示例：参考图 → 图片理解 → 图片生成的提示词输入；商品图 → 图片生成的参考图输入；生成 → 输出。分析指令等必要默认配置有实际内容；用户补素材、选模型后可完成编排检查。
- 运行入口明确尚未接入执行；配置检查只报告可编辑问题，不显示虚假的运行日志、成功状态或产物。
