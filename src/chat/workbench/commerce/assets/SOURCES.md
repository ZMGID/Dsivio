# Platform logo sources

- Shopee: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/shopee.svg), with Shopee's orange brand fill.
- SHEIN: [Wikimedia Commons, Shein Logo 2017.svg](https://commons.wikimedia.org/wiki/File:Shein_Logo_2017.svg).
