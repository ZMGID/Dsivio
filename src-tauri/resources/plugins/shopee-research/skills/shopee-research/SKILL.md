# 虾皮商品调研

输入商品图片、名称或链接，交付三类代表竞品及带图 Excel。结合图文与常识自主判断，提炼对选品有用的特点和差异，信息不全时也完成现有范围的调研。生成文件时读取 [报表规范](references/report-format.md)。

## 使用工具

- 网页：加载 `cua-driver`，使用 CUA MCP 的原生窗口观察、点击、输入和滚动。每步操作后读取新状态，确认结果。
- 浏览器：复用用户已打开的 Chrome 和登录状态，优先现有目标标签，需要时在同一窗口开标签。窗口不明确时让用户指定，Chrome 未打开时请用户打开。用户另选紫鸟等浏览器时，仍用 CUA。
- 本地数据：用脚本解析导出、计算排名和生成 XLSX。
- 本流程不用 Playwright、DOM/CDP 或其他网页控制通道，也不新开独立浏览器／配置。

## 开始调研

1. 读取 `~/.kivio/shopee-research/config.json`，仅保存 `site`（站点域名）、`outputDir`（绝对路径）、`reportFormat`（`default-nine-columns` 或模板绝对路径）。首次让用户选择站点和结果目录并保存；以后本次指定优先，用户要求记住时更新默认值。若新配置缺失而当前项目有旧的 `shopee-research.config-path.txt`，先读取它指向的配置并迁入上述位置。
2. 确认商品输入，只询问尚缺的信息；只问插件能力时先介绍，有具体商品后再调研。站点语言、币种从目标页面确认。
3. 用 CUA 确认 Shopee 可正常浏览。需要登录、验证码或系统授权时交给用户。虾多拉是可选辅助，可用时帮助找相似品或补充数据，用不了就直接在 Shopee 查找。CUA 或表格工具缺失时按 `shopee-research-setup` 补齐环境。
4. 在所选目录创建 `<本地日期>-<商品简名>-<站点>` 任务目录，同名时追加序号。保存 `progress.json`：商品、站点、关键词、当前步骤、原始文件路径、候选商品ID及已核验项。每阶段更新，继续任务时读取同一目录，复查页面状态后接着做。

## 执行流程

### 1. 搜索与采集

根据品类、外观和已知规格生成当地语言搜索词，用户给出的词优先。用 CUA 在 Shopee 搜索，结合商品图、标题和“相似商品”入口查找；虾多拉可用时辅助找相似品。记录实际关键词、页面排序和采集时间／时区，结果不相关时调整词。

默认记录当前搜索页可见的一批商品；相关且可比较的商品不足3条时再补一页或调整词补一轮。仍不足则交付现有样本，用户指定更大范围时按其范围采集。

逐条记录商品ID、标题、链接、价格和页面销量。虾多拉有可用导出时可直接导出，确认文件可读、数量对应，并保留原文件及字段口径。按商品ID关联图片，注明币种、销量期间及样本范围；初采缺项在候选详情阶段补齐。

### 2. 筛选竞品

按商品ID去重，依据品类、功能及形态筛选相关商品，记录排除原因和同款／近似款区别。用本地计算从同币种、同销量期间的样本中选：

- **销量最高**：累计销量最大。
- **销量居中**：累计销量升序，奇数取中间一条，偶数取中间两条中的较低一条。销量并列按商品ID排序。
- **最低标价且有销量**：销量大于0的商品中取最低链接标价；同价取销量最高者，再按商品ID排序。

排名使用确切数值；“1mil+”“10万+”保留原文，单列为未参与精确排名的样本。此时注明排名只覆盖精确值样本，整体排名未确认；精确数据不足时将候选标为暂定。只有近30天销量时统一按该期间重新筛选并改标题。重复命中的商品合并筛选标签。

### 3. 核验详情

逐个打开候选，结合商品图、详情图与文字提炼尺码、材质、包装、颜色、销量及GMV。图中的尺寸标注直接读取；外形、筒高、织法、花型、颜色等能看出的信息直接写，材质外观判断简短注明“看图”。缺少的厘米尺寸或成分比例留空。表格配图用 CUA 选择详情图库第二张，确认静态图片加载后截图，裁剪商品区域并按商品ID保存，不下载图片。结合规格选项、标题、详情图和售价判断核价SKU的销售单位与套餐数量，补齐实际价格、币种及折合单价；图文推断的数量简注依据。极少数仍无法判断这些关键项的SKU直接排除，换下一个候选继续调研。

- 最低价SKU须是目标商品、可选且有货；赠品、配件或缺货规格另记，换下一个有效候选继续核验。实际价变化时用已核验价格更新候选比较，未核验者保留暂定状态。
- 标价、每单位价格、优惠条件分别记录。页面价格与插件换算币种分开，销量保留链接口径。
- 主表只写有用的产品信息；非关键缺项留白，原始冲突保留在样本表。套餐数量与价格对应同一个SKU，厘米数值和成分比例读取图文标注。

### 4. 生成调研表

按 [报表规范](references/report-format.md) 用脚本批量生成和修改一份 `.xlsx`，文字、公式、列宽和行高一次写入；用随附脚本统一压缩截图并固定到图片格内。交付候选的SKU价格、销售单位、套餐数量及折合单价必须完整，缺项返回详情采集或替换候选。保留原始样本及核价输入，核对候选ID、链接、图片、价格、销量和公式，通过文件检查与渲染验收。软件兼容性实测使用独立副本，注明实际测试的软件。

交付文件，简要说明“本次样本内”的结论与实际覆盖数量。影响选品或核价的关键缺项集中说明一次。用户接管或流程受阻时停止输入，保存进度及恢复条件；续跑接着处理缺项。
