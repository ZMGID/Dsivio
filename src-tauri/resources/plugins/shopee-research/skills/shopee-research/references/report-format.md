# 调研表格式

用户模板优先；默认白底、细黑边框、居中换行。主表九列，文字都写入单元格。先整理数据，再批量生成固定布局，图片列宽和商品行高统一为160像素，其它列按内容设置宽度与换行，较长文字需要时增加对应行高。

## 主表：竞品调研表

表格上方用少量行写商品、站点、采集时间／时区、搜索词、原始与纳入样本数、实际销量期间。三类候选各一行，重复商品可合并筛选标签。

| 列 | 名称 | 填写规则 |
| --- | --- | --- |
| A | 编号／商品名称 | H1、H2、H3为本表编号，附筛选依据 |
| B | 图片 | 与商品ID对应的第二张静态截图，统一压缩后固定在对应图片格内；缺图标注缺失 |
| C | 产品规格（CM） | 读取图文尺寸标注，结合图片写尺码、筒高或外形；缺少的厘米尺寸留空 |
| D | 材质 | 图文成分与图片能识别的面料／织法；仅凭外观的材质判断简注“看图”，无信息留空 |
| E | 包装规格（CM） | 套餐数量及销售单位必填，与核价SKU对应；包装厘米尺寸缺少时留空 |
| F | 颜色／款式 | 结合卖家命名和图片提炼颜色、花型，并注明核价SKU |
| G | 竞品价格（币种） | 填有效SKU价格；价格无法判断时换SKU或候选，原始最低标价保留在样本表 |
| H | 竞品链接 | 可点击且完整的来源链接，必须与图片／商品ID一致 |
| I | 销量（期间） | 明确累计或近30天；“1mil+”等原始区间表达保留为文本 |

主表下方补充核价表：编号、SKU、价格、套餐数量／单位、折合单价、近30天销量／GMV、累计GMV、核验结论。

主表写有用的信息，非关键缺项留白，不用“未核实”“未披露”等占位句填满单元格。外形、筒高、织法、花型与颜色可按商品图判断；套餐数量综合规格选项、标题、详情图和售价判断，推断时简注依据；厘米数值和成分比例读取明确标注。来源冲突保留在原始样本。

单价公式为“核验SKU价格 ÷ 同一SKU套餐数量”，显示两位小数。交付候选的SKU价格、销售单位、正数套餐数量与折合单价必须完整；极少数无法判断时替换候选。主表价格和销量引用对应输入。金额和确定销量存数字，商品ID存文本，货币用单元格格式；链接使用可点击的完整地址。

## 第二张表：原始样本

保留原始导出文件。工作簿样本表收录所有采集记录，包括被排除项：

- 搜索序号、商品ID、原始标题、店铺、币种、标价／区间。
- 累计销量、近30天销量、对应GMV及来源原始字段名；期间未核实写“未确认”，不改名成确定的近30天。
- 商品链接、采集时间／时区、纳入比较与否、排除原因。
- 候选详情的原始规格、SKU、实际价格、套餐数量／单位、页面销量和冲突说明，放在同表详情区。

原始值与翻译／标准化值分开，缺失与真实0区分。GMV保留来源口径，页面和导出的冲突值并列记录。

来源集中注明搜索链接、导出文件名、详情链接与时间。导出图片按所在行关联到商品ID，再随ID匹配，排序后仍能对应。

## 验收

用脚本检查最终XLSX中的公式、记录数、候选数据、图片文件与关系链，再渲染检查图片对应、规格统一、文字完整。图片文件必须真实写入工作簿且关系可解析。软件兼容性实测使用独立副本，检查拖动、排序与保存重开；只有实际在WPS和Excel都验证过才报告双端通过，记录测试版本。结论说明样本范围和具体待核实项。

## 图片与导出

共用一份XLSX，图片用标准DrawingML嵌入文件，固定在对应图片格内，设为随单元格移动。启用无密码的图片对象保护，已有文字与数据保持可编辑。此方式优先保证不同软件可显示图片；它是锚定图片，不称为原生单元格图片，各软件的拖动、排序和保存行为以实测为准。

截图保留在任务目录；工作簿只存320×320白底JPEG缩略图，按比例留白，每张最多40KB。同图复用，可离线查看。图框统一156×156像素，商品行高160像素；导入软件的列宽换算可能不同，图框保持正方形。

复用以下脚本，避免每次重新写图片处理逻辑。Python环境需要Pillow、lxml。表格生成工具负责数据、公式、文字、样式和链接，先输出不带图片且未保护的`table-base.xlsx`，图片目标单元格保持空白。

`image-input.json`是列表，每项包含`sheet`（工作表）、`cell`（如B7）、`productId`、`path`（裁剪截图路径）。执行路径以本skill目录为准：

```bash
python scripts/prepare_images.py <任务目录>/image-input.json <任务目录>/thumbs
python scripts/embed_images.py <任务目录>/table-base.xlsx <任务目录>/thumbs/images.json <结果文件>.xlsx
```

第二步补充图片部件、图框尺寸与对象保护，保留已有内容、公式和链接。脚本输出图片数、去重后的存储数、图片字节数与最终文件大小。表格编辑直接修改文件；未做软件实测时如实标注，不把结构检查或生成预览称为软件验证通过。
