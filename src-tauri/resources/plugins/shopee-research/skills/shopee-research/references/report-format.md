# 调研表格式

用户模板优先。默认交付一份XLSX、一个工作表，白底、细黑边框、居中换行，内容只有顶部摘要、一段分析和按品类选择字段的竞品表。

顶部用简短摘要写商品、站点、日期、搜索词和比较范围；分析写产品差异、价格比较与选品判断，一段即可。竞品表结束就是成品结束，采集记录和核价过程留在任务目录。虾多拉GMV用于辅助筛选和顶部分析，不新增GMV列或原始样本页；比较GMV时统一币种、期间和商品／SKU口径。

以下是通用字段参考，实际根据商品和调研目标选择字段，不固定列数或品类模板。尺寸、材质、功能等有比较价值才保留；不需要的列整列省略。`features`可归纳当前商品的功能、配置、容量等特点。无需为了填表逐个查询无用信息。

| 列 | 名称 | 填写规则 |
| --- | --- | --- |
| A | 编号／商品名称 | H1、H2、H3及商品简称，筛选依据简短标注 |
| B | 图片 | 对应商品ID的清晰静态截图（列表图可用），压缩后固定在图片格内 |
| C | 产品规格（CM） | 图文尺寸标注及可判断的尺码、筒高、外形；缺厘米尺寸时省略 |
| D | 材质 | 图文成分及图片可识别的面料／织法；外观判断简注“看图” |
| E | 套装内容／销售单位 | 套餐数量及销售单位必填，匹配核价SKU；有包装尺寸时补充 |
| F | 颜色／款式 | 结合卖家命名和图片提炼颜色、花型，注明核价款式 |
| G | 竞品价格（币种） | 适用款式明确的页面价格；优惠条件在顶部说明 |
| H | 竞品链接 | 完整且可点击，与图片及商品ID一致 |
| I | 销量（期间） | 表头标明累计或近30天；“1mil+”等保留原文 |

结合图文与常识判断产品特点，主表写有用的信息，非关键缺项留白。套餐数量综合规格选项、标题、详情图和售价判断，推断时简注依据；厘米数值和成分比例读取明确标注。

价格、销售单位和正数套餐数量必须完整，极少数无法判断时替换候选。每件／每双价格本地计算，需要比较套餐价时写进顶部分析。金额和确定销量存数字，货币用单元格格式，商品ID存文本。

## 图片与生成

表格用随附Python脚本生成，依赖公开的openpyxl、Pillow、lxml，Dsivio内置Python（`dsivio python`）已自带。加载setup运行一次环境脚本后，从`~/.kivio/shopee-research/runtime/runtime.json`读取`python`路径；后续复用此环境，该路径失效时用`dsivio python`重跑环境脚本。

截图统一为320×320白底JPEG，按比例留白，每张最多40KB，同图复用。嵌入标准DrawingML图片，图框156×156像素，商品行高160像素，图片列足够容纳图框。设为随单元格移动并启用无密码对象保护，已有文字和数据保持可编辑；此方式为锚定图片，软件行为以实测为准。

把整理结果保存为任务目录的`report.json`，候选顺序即表格顺序：

```json
{
  "title": "虾皮巴西花纹袜调研",
  "summary": "巴西站；2026-10-08；meias florais；比较14条，按页面显示销量量级筛选。",
  "analysis": "七双装折合BRL 1.50/双，适合参考花卉中筒款。",
  "currency": "BRL",
  "salesPeriod": "累计",
  "candidates": [{
    "id": "25671923415", "name": "郁金香复古花纹袜", "role": "最低标价且有销量",
    "size": "均码；中筒", "material": "棉涤混纺；中等厚度",
    "qty": 7, "unit": "双", "salesUnit": "套",
    "quantityBasis": "包装数量结合成对袜图判断",
    "color": "粉、米白、绿、蓝；核价款号01", "price": 10.49,
    "sales": "40mil+", "url": "https://shopee.com.br/product/1006215031/25671923415",
    "image": "25671923415.png"
  }]
}
```

每次调研根据比较目标填写`columns`，按顺序指定实际出表字段：`name`、`image`、`size`、`material`、`features`、`package`、`color`、`price`、`url`、`sales`。其中`name/image/package/price/url/sales`必选，其余按品类取舍。省略时兼容原九列。以下仅为省略尺寸和材质、保留特点比较的示例，字段组合由本次调研决定：

```json
"columns": ["name", "image", "features", "package", "color", "price", "url", "sales"]
```

候选的`features`写影响购买和竞品比较的特点，`packContents`写对应售价包含的商品与配件。依据可见图文判断；承重、性能数值、安全认证等读取明确标注。

`qty`是价格对应商品包含的基础单位数量，`unit`是双／件等，`salesUnit`是套／件等。`size`、`material`、`color`、`role`按实际信息填写；`packContents`可简写套装内容，`packSize`有明确包装尺寸再加，`quantityBasis`仅推断数量时简注依据。`image`相对任务目录或绝对路径。每单位价格按`price / qty`计算，用于分析；候选ID唯一。

在本skill目录运行一条命令：

```bash
"<Python命令路径>" scripts/build_report.py <任务目录>/report.json <结果文件>.xlsx
```

## 验收

脚本统一生成表格、压缩截图、嵌入图片及可点击链接，检查最终文件后才替换结果文件，并把出表状态、文件检查及分段耗时写入`progress.json.report`。失败保留之前的成品。任务的整体完成状态在人工判断和布局复核通过后更新。

确认只有一个工作表，表内只有摘要、分析和竞品表。复核候选、关键字段、折合单价及分析，查看任务目录的`report-layout.html`检查前五款图文布局；HTML为独立布局预览，使用同一批文字和压缩图片，最终XLSX另作嵌入、链接和内容检查。多商品时复核较长文字所在行。

软件兼容性实测使用独立副本；未做实测如实说明，结构检查或预览不称为软件验证通过。采集样本、截图、SKU输入及来源冲突保存于任务目录，供续跑使用。
