# AiPrice图片搜款

已实测Chrome扩展`AiPrice(AliPrice)图搜 - 虾皮` v5.0.1，扩展ID `oanlehpljgeknlohgbakodejdbingjpj`。名字含虾皮，但本次版本图搜平台设置没有Shopee。

- 在普通网页右键图片 → AiPrice → 一键搜索同款 → 选择文件；弹窗可输入图片链接，也可用“一键截图”选择商品主体。
- 上传后左侧选择Amazon，顶部选择国家。当前实测选项为US、GB、JP、DE、ES、FR、IN、IT；其他站点以实际界面为准。
- Amazon Lite是另一入口，普通Amazon结果不足时再试。
- 结果卡片提供图片、名称、价格、评分及评价数；部分图片加载失败时打开商品页核对。点击卡片会在同一浏览器打开商品详情。
- 官网也可登录后点击搜索栏相机上传图片，但可选平台与扩展可能不同，优先用扩展。

2026-10-08实测：本地洗刷机图片 → Amazon US → CINGALOOK `B0D4VX3RF2`，详情页有透明杯、白底、灰色网盖和金色圈，外观高度一致。结果也夹有无关杯子、文具，需看图筛选。价格与评价是当时观察值，每次任务重新读取。
